Learning Website Deployment

Understanding how a project moves from my computer to the internet.

📅 July 2026 • GitHub • Vercel • Deployment

One of the most valuable parts of this assignment was learning how website deployment actually works. Before this project, I thought building the website was the final step. I learned that a website is not truly complete until it can be accessed online by other people.

For this project, I used Git, GitHub, and Vercel together. Git helped me track my changes, GitHub stored my project online, and Vercel turned my static website into a live site with a public web address.

I also learned how useful automatic deployment can be. Once my GitHub repository was connected to Vercel, new changes could be pushed to GitHub and Vercel would update the live website. That helped me understand how developers keep projects updated after the first version is published.

Deploying my own site made the project feel real. It was no longer just files saved on my computer. It became something I could share, test, and improve. This process gave me more confidence using professional tools that developers use in real-world projects.
